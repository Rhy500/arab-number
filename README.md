# Arabic Number Converter

A web application designed to convert standard Western Arabic numbers (0–9) into **Eastern Arabic numerals** (٠-٩).

> **Example:**  
> `1234` ➔ `١٢٣٤`

## 🛠️ Built With

This project is built using vanilla web technologies:
- **HTML5** (`index.html`): Markup structure for input fields and display[cite: 5].
- **CSS3** (`styles.css`): Visual styles and responsive layout[cite: 5].
- **JavaScript** (`script.js`): Logic to map and convert standard digits into Arabic numerals[cite: 5].
- **GitHub Actions** (`.github/workflows/static.yml`): Automated deployment workflow[cite: 5].

## 💡 How It Works

1. The user inputs standard digits (e.g., `1234`).
2. JavaScript maps each digit to its corresponding Eastern Arabic numeral:
   - `0` ➔ `٠`, `1` ➔ `١`, `2` ➔ `٢`, `3` ➔ `٣`, `4` ➔ `٤`, `5` ➔ `٥`, `6` ➔ `٦`, `7` ➔ `٧`, `8` ➔ `٨`, `9` ➔ `٩`
3. The converted result (`١٢٣٤`) is rendered on the screen instantly.

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser or run it using VS Code **Live Server**[cite: 5].
